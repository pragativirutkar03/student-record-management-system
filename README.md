# Student Record Management System

Python + Flask mini project inspired by Practical 10 and Data Structure Practical 1–9.

## Run locally
`pip install -r requirements.txt`
`python app.py`
Open `http://127.0.0.1:5000`.

## Deploy on Render
Upload the project files to a GitHub repository, create a Render Web Service connected to it, use build command `pip install -r requirements.txt`, start command `gunicorn app:app`, then click Deploy. The live URL is generated by Render. Demo records are stored in memory and reset when the server restarts; add a database for persistent storage.
